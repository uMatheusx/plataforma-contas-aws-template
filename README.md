# Plataforma de Contas AWS

Landing page com animação 3D guiada pelo scroll que apresenta a mudança das **contas DevOps** para as **contas de plataforma** na AWS.

- **Antes:** a conta AWS chega vazia e o time cuida de Traffic, Runtime, Storage, Integration e Events.
- **A virada:** essas frentes viram uma base de plataforma dentro da conta.
- **Agora:** o time pensa só no produto.
- **Final:** toda conta AWS nasce na nova Plataforma de Contas, conectada ao mesmo padrão.

## Como usar

É um único arquivo, `index.html`. Abra no navegador ou publique em qualquer hospedagem estática (GitHub Pages, S3, CloudFront).

Antes de publicar, troque os links de "Solicitar conta", "Abrir solicitação" e "Falar com o time" (estão marcados com comentários no HTML).

## Tecnologia

- [Three.js](https://threejs.org/) r147, carregado via CDN (jsDelivr)
- Fontes Geist e Geist Mono (Google Fonts)
- Tema claro e escuro automáticos, layout responsivo e suporte a `prefers-reduced-motion`
